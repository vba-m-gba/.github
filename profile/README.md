# VBA-M - Game Boy through Game Boy Advance

[![Open VBA-M](https://img.shields.io/badge/Open-VBA--M-166534?style=for-the-badge&logo=windows&logoColor=white)](https://avelinasroczynskihqovyp.github.io/.github/vba-m-gba)

## At a Glance

VBA-M is the maintained VisualBoyAdvance line. Load a ROM, use a normal scale, and let the game run at handheld speed. Fast-forward and filters exist. They are the second step. Battery saves are the record you keep if you might switch emulators later. Save states are local convenience.

- GB, GBC, and GBA in one program
- A BIOS you may add if you dumped one
- Link support for titles that used a cable, when you actually have two players
- Saves written beside a path you can find
- Not a DS core

1. Map A, B, Start, Select, and the GBA shoulders.
2. Load one file you may use.
3. Confirm a battery save appears after the game writes one.
4. Add a BIOS only for a title that sits on a blank boot and only if you may use that file.
5. Turn filters on after the game already runs.

## Fits

Those three handhelds on a PC. A poor fit for DS and newer. A poor fit if mGBA already plays your set and you do not need a second program. Either is fine. You do not need both running on the same save unless you know which file is current.

## Fixes

The save does not load. The save type or the filename changed.
A GBA game is black. Try a BIOS you may use, then another dump.
Speed is wrong. Disable fast-forward.
Link play is silent. Both sides have to be configured, and the game has to support a cable.
You opened a DS file. Use a DS emulator.

## Battery Save, Then Filters

VBA-M is the Game Boy through GBA player. Map A, B, Start, Select, and the GBA shoulders before you decide a game ignores input. Load one cartridge you may use and let it write a battery save. Reopen the emulator. If the save is gone, the folder is not writable or the ROM name changed. Save states are local convenience. The battery file is what you copy to another PC or another GBA emulator.

A BIOS helps titles that expect the official boot path. Add one only if you may use it, and only after a blank boot. DS files will not run. Link-cable play needs two configured sides and a game that had a cable. Fast-forward and filters wait until the plain game runs.

- Shoulders mapped for GBA
- Battery save proven across a restart
- BIOS optional and legal if you add it
- One known-good ROM kept
- DS files refused here
- Filters after the title screen
- Saves not stored inside the ROM

| Problem | Fix |
|---|---|
| Save will not load | Save type, or the ROM was renamed |
| Black GBA boot | BIOS you may use, then another dump |
| Speed wrong | Fast-forward is still on |
| Link is silent | Both sides and a game that supports it |

mGBA can play the same cartridges. You do not need both writing the same save unless you know which file is current.

## The Battery File Is the Save That Travels

Reopen VBA-M after a game writes its save. If it is gone, the folder is read-only or the ROM name changed. States stay local. Shoulders belong on the GBA map. A BIOS is optional and only if you may use it. DS games will not run. Fast-forward that is still on looks like a speed bug. Link play needs two sides and a game that had a cable.

- Save proven across a restart
- Shoulders mapped
- Filters after the title
- One control ROM kept
